## Commands

### Frontend (`frontend/`)
```bash
npm install          # install dependencies
npm run dev          # dev server on :3000
npm run build        # production build
npm run lint         # ESLint
```

### Backend (`backend/`)
```bash
composer install                    # install dependencies
php artisan migrate                 # run migrations
php artisan db:seed                 # seed (creates admin@speedservice.bj)
php artisan serve                   # dev server on :8000
composer test                       # run PHPUnit tests (= php artisan test)
php artisan test --filter=TestName  # run a single test
```

### Docker (full stack)
```bash
docker compose up -d        # start all services (frontend :3000, backend :8000, postgres :5432, redis :6379)
docker compose down         # stop all services
docker compose logs backend # tail logs for a service
```

### Mockup (local visual reference only — not tracked in git)
```bash
cd "SpeedService UI_UX Mockup" && npm i && npm run dev   # Vite dev server
```

## Architecture

### Overview
Full-stack delivery platform for Bénin. The frontend and backend are completely decoupled: the frontend calls the Laravel REST API over HTTP.

```
frontend/   → Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 3
backend/    → Laravel 12 + PHP 8.4 + PostgreSQL + Redis + Laravel Sanctum
```

### Frontend (`frontend/`)
- **Router**: App Router (`app/` directory). Pages go in `app/`, shared UI in `components/`, helpers in `lib/`.
- **Styling**: Tailwind CSS 3 with `cn()` (clsx + tailwind-merge) from `lib/utils.ts`. The mockup's design tokens are: primary `#861D6D`, secondary `#B24799`, background `#FAF7FB`, foreground `#1D1D1F`; font is Inter. These are not yet wired into `tailwind.config.ts` — add them there when implementing sprint screens.
- **Components**: `Button` (CVA variants: default/outline/secondary, sizes: default/sm/lg) and `Card` (compound component with `Card.Header`, `Card.Title`, `Card.Description`).
- **API calls**: not yet implemented — will use `NEXT_PUBLIC_API_URL` pointing to the Laravel backend.

### Backend (`backend/`)
- **Auth**: Laravel Sanctum, token-based (SPA tokens). Protected routes go under `Route::middleware('auth:sanctum')` in `routes/api.php`.
- **Primary keys**: all models use `HasUuids` — PKs are UUIDs, not auto-increment integers.
- **Enums**: all domain enums are PHP backed string enums in `app/Enums/`. Always cast enum columns in model `casts()` — never use raw strings.
- **User roles**: `UserRole::Client | Driver | Admin` — role is stored on the `users` table, no separate roles table.
- **Delivery lifecycle** (9 ordered statuses in `DeliveryStatus`):
  `Draft → AwaitingPayment → AwaitingValidation → Confirmed → Assigned → PickingUp → InDelivery → Delivered | Cancelled`
- **Payment methods** (`PaymentMethod`): `MtnMomo`, `MoovMoney`, `Card`, `CashOnDelivery`, `Agency`. The last two require manual admin validation (status stays `AwaitingValidation`).
- **Package taxonomy**: `PackageType` (Document/Small/Medium/Large) determines the base price; `ContentCategory` (Document/Clothing/Electronics/Food/Other) is metadata only.

### Key relationships
```
User (client) --< Delivery >-- User (driver)
Delivery --1 Payment
Delivery --< DeliveryStatusHistory
User --< Address
```
